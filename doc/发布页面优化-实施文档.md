# 发布页面优化 - 实施文档

## 问题1：修改应用配置后，界面环境没有切换

### 根因分析

文件：[src/views/home/index.vue](src/views/home/index.vue)

流程：
1. 用户点击「修改」→ `onOpenAppConfig()` (line 3158) → 打开 `appconfigDialog`，传入当前应用配置数据
2. 在对话框中，**环境 radio 是可以修改的**（`state.ruleForm.environment`，对应数据库 `t_app_config.environment`）
3. 用户修改环境（如 Dev→Uat）并保存 → `updateAppconfig()` 将新环境写入数据库 → `emit("refresh")`
4. 主页 `@refresh="getPublishAppconfigs()"` — 使用 `state.publishData.environment`（**仍是旧值**）去查询，查不到已保存的新环境配置

**结论**：`state.publishData.environment` 未与对话框中修改的 environment 同步。

### 修复方案

在 [src/views/home/index.vue](src/views/home/index.vue) 中：
1. 将 `@refresh="getPublishAppconfigs()"` 改为 `@refresh="onAppconfigRefresh"`
2. 新增 `onAppconfigRefresh` 方法：先从数据库重新读取修改后的配置，同步 `environment`，再刷新

```typescript
const onAppconfigRefresh = async () => {
    if (state.publishData.appconfigData.id) {
        const result = await appconfigDb.getAppconfigById(state.publishData.appconfigData.id);
        if (result.code === 0 && result.data.data) {
            state.publishData.environment = result.data.data.environment;
        }
    }
    await getPublishAppconfigs();
};
```

## 问题2：应用启动时自动刷新发布信息，去掉 localStorage

### 根因分析

当前逻辑：
- `onBeforeMount` (line 3408) → `getProjectDefault()` (line 3169)
  - 获取默认项目 → 扫描哪些环境有配置 → `restoreEnvironmentFromStorage(projectId)` 尝试从 localStorage 恢复上次环境 → 使用该环境
- `onProjectChange()` (line 3316) → `restoreEnvironmentFromStorage(val)` 恢复该项目之前保存的环境
- `onEnvironmentChange()` (line 3341) → `saveEnvironmentToStorage()` 保存环境到 localStorage

这导致：
1. 启动时依赖 localStorage，而非直接查数据库
2. 环境切换被持久化到 localStorage，造成跨启动"记忆"

### 修复方案

在 [src/views/home/index.vue](src/views/home/index.vue) 中：

1. **删除** `saveEnvironmentToStorage` 函数（lines 3243-3250）
2. **删除** `restoreEnvironmentFromStorage` 函数（lines 3253-3262）
3. **简化** `getProjectDefault()`：移除 localStorage 恢复逻辑，直接用第一个有配置的环境（Dev 优先）
4. **简化** `onProjectChange()`：移除 `restoreEnvironmentFromStorage` 调用，默认 environment=1
5. **简化** `onEnvironmentChange()`：移除 `saveEnvironmentToStorage` 调用
